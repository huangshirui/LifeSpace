# LifeSpace Identity

Global authentication and SSO service for LifeSpace applications.

## Planned scope

- Global users
- External identity mappings
- Application/client registration
- Browser login and SSO
- Authorization Code + PKCE
- Short-lived access token issuance
- Refresh/revocation and key lifecycle

Identity authenticates principals and applications. Space membership, Data Grants and life-domain authorization remain Core responsibilities.

This directory is a scaffold only; no Identity protocol/API is considered implemented until a canonical contract and tests are added.
